# My Website

A simple, responsive website built with HTML, CSS, and JavaScript.

## Features

- Responsive design that works on desktop and mobile devices
- Smooth scrolling navigation
- Clean, modern layout
- Fixed header with navigation
- Organized file structure

## Project Structure

```
website/
├── index.html          # Main HTML file
├── css/
│   └── style.css      # Stylesheet
├── js/
│   └── script.js      # JavaScript functionality
├── images/            # Image assets (empty for now)
└── README.md          # This file
```

## Getting Started

1. Clone this repository
2. Open `index.html` in your web browser
3. Or serve it using a local web server for development

## Development

To run a local development server, you can use:

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (if you have http-server installed)
npx http-server

# PHP
php -S localhost:8000
```

Then open http://localhost:8000 in your browser.

## Customization

- Edit `index.html` to modify the content and structure
- Update `css/style.css` to change the styling
- Add functionality by editing `js/script.js`
- Add images to the `images/` directory
